# FlowDesk AI

An AI-powered dashboard concept for small business automation — centralizing 
customer conversations, lead scoring, and smart reply suggestions in one place.

## 🎯 What it does

FlowDesk AI simulates a SaaS product built for small businesses that need to manage 
customer conversations and leads without hiring a full support team. It combines a 
CRM-style Kanban board, an AI-assisted inbox, and an automation control panel.

## ✨ Features

- **Smart Inbox** — Unified conversation view with AI-generated reply suggestions 
  and lead interest scoring (0–100)
- **Kanban Lead Management** — Drag-and-drop pipeline from New Lead to Closed Deal
- **Automation Panel** — Toggle-based automation rules (auto-reply, follow-up 
  scheduling, urgency classification) with execution tracking
- **Analytics Dashboard** — Real-time metrics on response time, conversion rate, 
  and lead volume

## 🛠️ Built with

- Typescript
- React
- Modern dark-mode UI, fully responsive
